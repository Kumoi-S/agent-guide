# Agent 使用：从入门到进阶

正式内容按 45 分钟安排，答疑另计。三个实验分别观察任务表达、材料提供和工具执行对交付的影响。

## 一、开头与 Harness 基本组件导览（5 分钟）

- **开场引入。** 介绍本次分享的内容和要回答的四个问题，接着第一问「我会用网页 AI，Harness 能额外给我什么？」进入 Harness 介绍。
- **Harness 和网页 AI 的区别。** 从网页端已有 Agent 模式讲起，用 ChatGPT 的默认使用体验作例子。Harness 的区别在于使用者可以按工作需要自定义各个组件。
- **认识 Harness 的组件。** 先用示意图介绍 Harness 有哪些组件，再切到实际界面或用提前准备的画面，带大家认一下。

## 二、Prompt Engineering（9 分钟）

- **从一句需求到一份可执行的委托。** 任务目标、背景与依赖材料、要求和约束、交付形式、验收标准。
- **两个模型 × 三种交代方式。** 对比简单许愿、结构化 Prompt、短指令加 Skill。重点是哪些要求落实了、哪些遗漏影响使用、拿到结果还要改多少。
- **两个短对照。** 角色设定能否改变结果里的实际判断。发现问题后，把稳定要求补回原指令，和在当前会话里追加纠正各适用于什么情况。
- **衔接 Context。** Skill 组的指令很短，部分工作要求由 Skill 提供。由此进入 Context。

## 三、Context Engineering（9 分钟）

- **从 Skill 引出 Context。** 用 Prompt 实验中实际使用的 Skill 讲清工作方法如何交给模型。Context 的定义一句话带过，结合 Pi 说明任务指令、读到的资料和工具结果如何成为模型这一步可用的信息。
- **同一任务、两种材料条件。** 固定任务和模型，比较加一份相关规范或模板前后的结果。分别看补充材料有没有被读取、其中的要求有没有落实到交付物。
- **Skills 的日常使用。** 怎么选与任务相关的 Skill，什么时候显式指定，怎么判断它发挥了作用。用一条重复出现的工作规范说明什么值得沉淀成 Skill。

## 四、Harness Engineering（12 分钟）

- **Codex 与 DSH 的工作方式。** 通过真实界面说明文件操作、文档或网页批注与修改、界面查看和工具执行。重点是能做什么、执行到哪一步在哪里看。
- **结构化绘图实验。** 用同一份流程描述对比 Draw.io、Excalidraw 等方案。比较结构正确性、布局、可编辑性和局部修改成本。保留一次现场局部修改，说明为什么要检查实际源文件。
- **执行控制。** 简要说明沙箱、允许操作的范围以及哪些操作需要人工确认。工具选择落在这次工作的交付要求上。

## 五、一些实用技巧（7 分钟）

- **多模型管理。** 用 Mapie 讲模型切换和按任务选模型。模型特点结合实际使用的版本。
- **信息安全与脱敏。** 内部材料在哪些获准环境使用，哪些信息要替换，哪些业务关系必须保留。
- **验收标准。** 提前约定怎么检查事实正确性、内容完整性、逻辑合理性和交付格式。
- **知识沉淀。** 把反复用到的业务规则、判断标准、模板和工作方法留下来。保留能说明适用条件的案例和失败经验。

## 六、总结（3 分钟）

回收三个实验。把事情说清楚，把信息给正确，让 Agent 真正执行，最后检查交付。落到一项手头已有、结果容易检查的工作。
