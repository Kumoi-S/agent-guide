# 目标听众画像与关键疑惑

## 目标听众画像

- **使用起点。** 11 月 20 日与饶博的第三次沟通确认，大家已经熟悉网页端 AI，DSH 刚开始用。对话、上传材料和生成结果，是可以直接借用的经验。
- **岗位与案例。** 售前、运维、实施、需求管理、产品、开发和算法同场。阅读材料、核对要求、修改交付物是大家都能理解的工作。案例的专业性可以体现在真实的业务规则和验收口径上。
- **讲解深度。** 网页 AI 的使用经验可以直接借用。Skill、MCP 和执行权限等概念，讲到有助于理解任务为什么这样做、自己能在哪里干预。

## 关键疑惑

**网页 AI 已经能传材料、出结果，我什么时候会用到 DSH？**  
当任务需要在现有材料上持续工作时，目录、工具和操作权限会影响交付。讲清楚这些条件怎样改变工作方式，听众才有理由换环境。

**同一件事，我要交代到什么程度？**  
用对照实验回答。不同写法究竟改变了什么，哪处遗漏我拿到手就得改。再分清两种返工原因。一种要补交代，一种要补材料。

**Skill 装好了，到底有没有帮上忙？**  
这是理解 Context 的入口。找到这次实际提供的那条工作要求，再看 Agent 读到了什么、产物哪一处体现了它。这样也能讲清楚为什么要围绕具体任务选 Skill。

**Agent 说做完了，我怎么判断能交付？**  
执行记录能说明发生过什么操作。能不能交付，要打开结果按要求核对。拿绘图来说，要能打开源文件、顺着分支走到正确的步骤，还要核对指定的改动。
